# Class 1 — Linux Architecture

**Status:** Lesson completed  
**Learning path:** Ubuntu Server Administration

## Learning objective

Understand the main components that make up a Linux operating system and how they work together.

## Topics covered

- **Kernel:** The core of the operating system. It manages hardware resources, memory, processes, devices, and communication between software and hardware.
- **Shell:** A command interpreter that accepts commands and provides an interface for interacting with the operating system. Examples include Bash and Zsh.
- **Distribution (distro):** A complete operating-system package built around the Linux kernel, together with system utilities, package management, libraries, and applications. Examples include Ubuntu and Kali Linux.
- **Applications:** Programs that perform user or administrative tasks, such as text editors, web servers, browsers, and monitoring tools.

## How the components relate

Applications and user commands run in user space. The shell interprets commands and starts programs. When software needs operating-system services, it makes requests that are handled by the kernel. The Linux distribution brings the kernel and the surrounding software together into an installable operating system.

## Key distinction

Linux commonly refers to the kernel, while Ubuntu and Kali Linux are distributions built around that kernel. A shell is an interface for issuing commands; it is not the kernel itself.

## Reflection

This lesson establishes the vocabulary needed to understand Linux administration and distinguish the operating-system kernel, command interface, distribution, and applications.
