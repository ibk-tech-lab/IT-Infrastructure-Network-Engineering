Ubuntu Server Administration

Overview

This section documents my learning journey and practical experience in Ubuntu Server Administration as part of my professional development towards becoming a Network Engineer or IT Infrastructure Engineer.

The course focuses on developing the technical knowledge and hands-on skills required to install, configure, manage, secure, monitor, and troubleshoot Linux-based server environments.

Ubuntu Server is a widely used Linux operating system for hosting applications, managing network services, deploying infrastructure, and supporting enterprise IT environments. Understanding its administration is an important foundation for working in modern IT infrastructure and networking.

 Learning Objectives

Through this course, I aim to:

1. Understand Linux operating systems and the Ubuntu Server environment.
2. Install and configure Ubuntu Server using Oracle VirtualBox.
3. Develop confidence in using the Linux command-line interface (CLI).
4. Understand Linux directory structures and file management.
5. Create, manage, and administer users and groups.
6. Configure file ownership, permissions, and access control.
7. Understand Linux networking, IP addressing, and network configuration.
8. Manage software packages, system updates, and essential services.
9. Monitor system resources and troubleshoot common server problems.
10. Develop practical server administration skills through real-world laboratory exercises.
